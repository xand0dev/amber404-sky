## План Б: ECMWF Open Data (T6, перевірено 2026-11-27)
| Що | Open-Meteo (зараз) | ECMWF Open Data, IFS |
|---|---|---|
| Ліцензія | CC BY 4.0, **лише некомерційно**; комерція — платна підписка | CC BY 4.0 + ECMWF Terms of Use, **комерційно можна** з атрибуцією «© ECMWF»; доставка великих обсягів може мати сервісні збори |
| Сітка | ≈ 0.1–0.25° (моделі за вибором Open-Meteo), API на точки | 0.25° (з 20.10.2026 ще й 0.1°), GRIB2, файли за кроками |
| Час | щогодини, 48 год | прогони 00/06/12/18 UTC, крок **3 год** — для годин треба інтерполяція в часі |
| Вітер біля землі | 10, 80, 120, 180 м | 10 м і 100 м (`10u/10v`, `100u/100v`) |
| Рівні тиску | 1000, 975, 950, 925, 900, 850 | 1000, 925, 850, 700… (u, v, gh) |
| Пориви, t, опади, rh | є | `10fg`, `2t`, `2d` (rh через точку роси), `tp` |
| Видимість | є | **немає** |

Висновок: для комерційної версії ECMWF підходить як джерело вітру й температури (той самий §6.2-профіль з меншою кількістю рівнів), але потрібні GRIB-декодер (ecCodes / cfgrib — нова залежність, PR у F0), інтерполяція 3 год → 1 год і окреме джерело видимості. Джерела: https://www.ecmwf.int/en/forecasts/datasets/open-data, https://confluence.ecmwf.int/display/DAC/ECMWF+open+data%3A+real-time+forecasts+from+IFS+and+AIFS, https://apps.ecmwf.int/datasets/licences/general/, https://open-meteo.com/en/terms.
