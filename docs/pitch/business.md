# AMBER//404 Sky — бізнес-модель і конкуренти

F2 · C-AC (`docs/SPEC.md` §9). Джерело правди — `docs/SPEC.md`; за розбіжності перемагає вона.
Усі ціни конкурентів — з публічних сторінок у сторах (перевірено 2026-11-27, ціни для US App Store у USD). Наша ціна — **гіпотеза** (`assumption`), не перевірена на клієнтах; доходів і розміру ринку не вказуємо.

## 1. Хто користувач і що болить
- **Екіпажі дронів Сил оборони** — FPV 7–10″, важкі мультикоптери, крила VTOL (SPEC §2).
- **Агро** — оператори агродронів і сервісні компанії: той самий вітер, інший дрон (SPEC §2).
- **ДСНС і розмінування** — той самий рушій погоди й вердикту (SPEC §2, §12).

Біль зі слів оператора (дзвінок 26.11, SPEC §1–2): дивляться вітер по висотах (мале небо до ~90 м, шари до 500 м) і точку роси; зараз поєднують Windy (карта без вердикту) і UAV Forecast (вердикт без карти, одна точка, **одна підписка на п'ятьох**).

## 2. Бізнес-модель
| Сегмент | Доступ | Чому |
|---|---|---|
| Сили оборони, ДСНС, розмінування | **Безкоштовно** | Суспільна місія й dual-use (SPEC §12); тут ми отримуємо відгуки й довіру |
| Агродрони: оператори й сервісні компанії | **Платна підписка на команду** | Комерційна робота, вітер напряму впливає на якість обприскування й кількість льотних годин |
| Агрохолдинги, страхування, планування сезону | Платний звіт клімату ERA5 (пізніше) | Частка льотних годин за місяцями (SPEC §7.8) — це історична статистика, якої немає в прогнозних застосунках (SPEC §8) |

**Дані й ліцензії — умова платної версії.** Open-Meteo Forecast — CC BY 4.0, **лише некомерційно** (SPEC §8). Хакатонна версія некомерційна; платна версія переходить на ECMWF Open Data або платну підписку Open-Meteo (SPEC §12). Ліцензію ECMWF Open Data ще треба перевірити (SPEC §8) — до перевірки комерційний запуск не обіцяємо.

**Витрати.** Без backend-сервера: статичні JSON на GitHub Pages, оновлення через GitHub Actions кожні 3 год (SPEC §5). Головні змінні витрати платної версії — ліцензія погодних даних і обчислення конвеєра; суми не оцінювали (`assumption`: потрібен розрахунок після вибору джерела).

**Канали.** Безкоштовна версія — через самих операторів (сарафанне радіо, одна підписка на п'ятьох уже показує, що застосунком діляться в екіпажі). Агро — через сервісні компанії агродронів і агро-виставки. Конкретних партнерів не називаємо — не домовлялись.

## 5. Відмінність
1. **Карта країни з вердиктом.** Windy дає карту без вердикту, UAV Forecast — вердикт для однієї точки. У нас вся Україна фарбується GO / CAUTION / NO-GO для обраного дрона й висоти (SPEC §3).
2. **Космічні дані ЄС, яких немає в прогнозних застосунках.** Copernicus ERA5 — історична частка льотних годин за місяцями (SPEC §7.8): «чи варто планувати сезон обприскування на грудень». Galileo — незалежна від GPS геометрія супутників (PDOP) (SPEC §7.7, §8).
3. **Веб без встановлення.** Відкривається у штабі на ноутбуці й на телефоні як PWA, працює офлайн (SPEC §4, §7.11). Конкуренти — мобільні застосунки, Windy — без профілю дрона.
4. **Модель «на команду».** Безкоштовно для оборони, ДСНС і розмінування; агро платить за команду, а не за людину — під реальну звичку «одна підписка на п'ятьох».
5. **Чесність даних.** Найкращий статус — «в межах профілю», ніколи не «безпечно»; немає даних — «немає даних», ніколи не GO; видно джерело й час прогнозу (Конституція 1, 7).

**Чесно про 17 METEO.** Це найсильніший конкурент: український, безкоштовний, має профілі дронів, вердикт з причиною, точку неповернення й GNSS-монітор. Наша різниця з ним — карта всієї країни з вітром по висотах, зона польоту на карті, паливні крила, вебверсія для штабу без встановлення (SPEC §12). **Перевірити руками до пітчу** (SPEC §12): поставити 17 METEO, подивитись, чи є в нього карта країни; до перевірки не стверджуємо, що ми кращі.
