# Конституція AMBER//404 Sky

1. **Продукт.** Веб-карта погоди для екіпажів дронів Сил оборони над Україною (мілтех) і агро (dual-use): вітер на висотах польоту, пориви, обмерзання, видимість, GNSS — і вердикт GO / CAUTION / NO-GO для конкретного дрона на кожну годину. Демонстраційна модель, не офіційний метеопрогноз. Найкращий статус — «в межах профілю», ніколи не «безпечно».
2. **Джерело правди** — `docs/SPEC.md`. Spec фічі (`specs/F<N>/spec.md`) уточнює, але не суперечить їй. За розбіжності перемагає `docs/SPEC.md`.
3. **Стек.** `pipeline/` — Python 3.12 (uv, ruff, pytest) збирає дані й пише статичні JSON у `web/public/data/`. `web/` — Vite + React + TypeScript (strict), карта на Canvas 2D (поле й частинки вітру) + SVG (кордони, міста). Без backend-сервера й без ключів у браузері. Сайт — GitHub Pages, PWA (спершу телефон, офлайн). `web/src/core/` — чистий TS без DOM.
4. **Контракти.** Формат кожного JSON — у `contracts/*.schema.json`, приклади — у `contracts/mocks/`. Pipeline і web тестують себе на цих mocks. Змінює контракти лише власник F0 окремим PR з міткою `contract`; поки PR немає — працюємо на mocks.
5. **Папки.** Кожен пише лише у свої шляхи з SPEC §9, плюс `specs/F<N>/**` і свій розділ у `docs/AI_LOG.md` і `docs/SOURCES.md`. Тести поруч із кодом.
6. **SDD.** Spec → тести з AC (red) → мінімальний код (green). Поведінка змінюється спершу в spec. AC не послаблюємо, щоб сховати збій.
7. **Чесність даних.** Жодних вигаданих даних чи чисел. Кожен ліміт дрона й поріг має джерело (паспорт виробника) або позначку `assumption`. Mock на екрані підписаний «MOCK». Немає даних = «немає даних», ніколи не GO. На екрані видно джерело і час прогнозу.
8. **Мілтех, але лише погода.** Користувач — екіпажі FPV, важких мультикоптерів і крил. Продукт відповідає на одне питання: «чи можна летіти, на якій висоті й куди дістанемо». Жодних цілей, наведення, планування уражень, лінії фронту, відстеження дронів. **OPSEC:** точки й маршрути користувача не йдуть на сервер — лише в браузері (localStorage), сайт працює зі статичних файлів. Кордони — лише версія з українською точкою зору (Крим — Україна).
9. **Merge.** `make check` зелений, PR не draft, лише свої папки → мерджить власник фічі. PR зі спільними файлами мерджить власник F0.
10. **AI.** Код генерують агенти Claude Code, люди пишуть spec і перевіряють AC руками. Кожна AI-сесія — рядок у `docs/AI_LOG.md`. Без підписів агентів у комітах і PR.
11. **З нуля.** Код створюється на хакатоні (з 27.11, 18:00 CET) у цій репі. Спека й дизайн готові заздалегідь, код — ні. Прототип-артефакт — лише референс вигляду, його код не копіюємо. Ліцензія Apache-2.0.
